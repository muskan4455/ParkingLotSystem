# Parking Lot Management System

A Low-Level Design (LLD) implementation of a Parking Lot system using Java and Spring Boot.

## Features

* Multi-floor parking lot
* Multiple parking spots per floor
* Support for different vehicle types
* Vehicle-to-spot allocation
* Park and release operations
* In-memory state management
* Thread-safe parking operations
* REST APIs for parking operations

## Tech Stack

* Java
* Spring Boot
* REST APIs
* Object-Oriented Design
* In-memory data structures

## LLD Concepts

* Encapsulation
* Composition
* Enums
* Separation of responsibilities
* Thread safety
* Extensible parking spot and vehicle modeling
